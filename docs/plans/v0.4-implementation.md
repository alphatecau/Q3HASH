# v0.4 implementation sequence

**Status:** Work packages 1–4 delivered through 0.4.0.dev3; search CLI and final release gates remain pending.
**Date:** 1 November 2026.
**Contract:** [Bounded encoding search v1](../contracts/encoding-search-v1.md).

## Outcome

Given one fixed logical computation, generate a bounded set of declared encodings,
check supplied physical circuits with the existing complete-subspace verifier and
report exact structural trade-offs with reproducible candidate/rejection evidence.
The first result is a research comparison, not a claim of globally optimal or
hardware-superior compilation.

## Work packages and dependencies

| Order | Proposed files | Deliverable and acceptance gate |
| --- | --- | --- |
| 1 | `search.py`, `tests/test_search_models.py` | Immutable constraints/candidates/reports, schema/ID rules, strict validation and preflight; satisfy VAL and serialization input cases. |

| 5 | `search_cli.py`, `tests/test_search_cli.py` | Read explicit inputs and emit strict versioned reports; human-readable output explains bounds and missing circuits; no default “best encoding” headline. Depends on 4. |

Routine implementation choices may be resolved within the contract. A new map
family, larger physical space, hardware objective or changed logical semantics
requires a documented contract change with new independent vectors.

Current delivery: work packages 1–4 implement generation, exact structural counts,
verified supplied-circuit Pareto comparison, cumulative call/work budgets and the
strict aggregate SearchReport. The existing 120-test baseline adds 41 tests for
preflight, budget precedence, complete status coverage, entangling/reordered-axis
workloads, canonical reports and adversarial decoding.

The independent generator audit covers 504 cases; the resource/comparison audit
covers 2,433 instruction sequences, 1,008 abstract dominance pairs and 189 fronts.
The aggregate audit covers 324 budgeted runs, 236 circuit verifications and 324
snapshot replays using a separate remaining-budget and explicit event-count oracle.
Decoders validate recorded evidence without new numerical calls. The package is
`0.4.0.dev3`, not the v0.4.0 release. Next implement the CLI and complete the
release gates in packages 5–6. Website integration remains deferred.

## Benchmark progression

1. **Qutrit shift:** retain the existing logical program and explicit three-gate
   two-qubit implementation. Add the native qutrit as a supplied circuit. Both
   pass. Compare the six exact counts from the contract; both lie on the default
   front, while excluding maximum register dimension changes that front.
2. **Entangling workload:** native qutrit Fourier-plus-SUM checks the full 9-state
   operator. A mixed `(2,3)` workload and its physically reordered `(3,2)` circuit
   verify axis/basis conventions under an explicit seed. Missing alternative
   circuits remain unimplemented; do not manufacture a reference matrix and call
   it a compiled circuit.
3. **Adversarial workloads:** leakage, relative-phase disagreement, malformed
   injections, false cost claims, unsupported dimensions and exhausted budgets.
   Every report must make omissions and coverage limits inspectable.

## Verification and release gates

- Keep `python tools/check_search_contract.py` as the independent reference-vector
  audit using the existing verifier, and compare the public generator with
  `python tools/check_search_generation.py`. Their success is not v0.4 completion.
- Retain the 72-test v0.3 baseline, original numerical audit and complete-operator
  audit unchanged. Add focused production tests rather than replacing the oracles
  with production helper calls.
- Test exact natural-exhaustion boundaries and each independent budget. Inspect
  counter conservation and confirm that allocation occurs only after checks.
- Demonstrate byte-identical canonical reports for repeated fixed inputs in the
  same recorded numerical environment. A
  partial front must retain its partial/missing-circuit disclosure.
- Build wheel/source distributions in clean environments across Python 3.10–3.13;
  require CI for the exact release commit and verify the tagged source identity.

## Remaining deliberately deferred work

General synthesis of physical circuits, automatic inference of logical dimensions,
unbounded or all-injection searches, physical gate durations/error rates and web
runtime reconciliation remain outside this first search implementation. v0.5 owns
hardware-conditioned comparisons; v0.6 owns the unified research demonstration.
