# Contributing

Issues, reproducible tests, documentation and scientifically grounded criticisms are welcome.

1. Explain the problem and expected behaviour, including dimension assumptions.
2. Add tests for code changes (`python -m unittest discover -s tests -v`).
3. Distinguish demonstrated capabilities from proposed features.
4. Do not submit benchmarks without a reproducible method and baseline.

This project is early-stage; security-critical or production use is not recommended.
