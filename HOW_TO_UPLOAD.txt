Q3HASH GITHUB UPLOAD INSTRUCTIONS

1. Extract Q3HASH-upload-ready.zip locally.
2. In Chrome on a computer, visit https://github.com/alphatecau/Q3HASH
3. Choose Add file > Upload files. Drag the CONTENTS of the extracted folder (not the ZIP file) into GitHub. Preserve all nested folders.
4. Replace README.md and CONTRIBUTING.md if prompted. Commit to main.
5. Verify repository contains: pyproject.toml, src/q3hash/core.py, tests/test_core.py, examples/qutrit.q3, .github/workflows/tests.yml.
6. Open the Actions tab and check Python tests status.
7. Remove previous top-level duplicate core.py, cli.py, __init__.py, test_core.py, architecture.md, language-spec.md and roadmap.md after checks pass; do not remove LICENSE or .gitignore.

IMPORTANT: Uploading the ZIP itself does NOT extract files on GitHub.
