# Six-month Q3# research roadmap (proposed)

Milestones are targets, not delivered features.

1. **Month 1 — Foundations:** public repository, reproducible examples, parser, statevector baseline, and regression tests.
2. **Month 2 — Formalise semantics:** typed IR, richer gate set and multi-register operations; independent correctness tests.
3. **Month 3 — Inference:** candidate dimension/encoding generation, constraints, exhaustive small-case validation.
4. **Month 4 — Resource models:** benchmark design and hardware-conditioned depth/gate/fidelity tradeoffs, uncertainty reporting.
5. **Month 5 — Verification:** equivalence tooling, reference implementations and benchmark reproducibility.
6. **Month 6 — Demonstration:** end-to-end benchmark suite, technical report and peer-reviewable public examples.

Every milestone requires executable tests and documented limitations before status can change to complete.
